## Intent

Demo pitch video presenting the FoodLink platform. Showcases how merchants list surplus food to prevent waste, how customers receive alerts and reserve meals at great prices, and the simple in-person verification code handoff. Rendered on a 16:9 widescreen presentation canvas with sleek mobile device mockups displaying both the merchant and customer web apps.

## Assets

- https://foodlink-beige.vercel.app — Customer web app (listing discovery, reserve meal, pickup code)
- https://foodlink-merchants.vercel.app — Merchant web app (surplus food listing, order notifications, code verification)

## Customizations

- Dual mobile device mockup staging (Customer and Merchant apps side-by-side or alternating spotlight).
- Visual live alert simulation when merchant posts a surplus listing.
- Verification code reveal and merchant validation celebration animation.

## Notes

- Modern pitch presentation aesthetic.
- Clean typography and vibrant green/orange palette reflecting freshness, sustainability, and food.
