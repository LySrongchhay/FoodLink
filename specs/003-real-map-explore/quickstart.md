# Quickstart Guide: Real Geographic Map for Customer Explore

**Feature**: `003-real-map-explore`  
**Target Directory**: `d:\DGIY\foodlink-2\foodlink-ui`  

---

## 1. Running the Updated Map View

```bash
cd foodlink-ui
npm.cmd run dev
```

1. Open `http://localhost:5175/customer` in your browser.
2. In the bottom navigation bar, tap the **"Explore" (Compass icon)** tab.
3. Observe:
   - Genuine Phnom Penh streets (Norodom, Monivong, Sihanouk Blvd, St. 310) and rivers.
   - Branded CAD Bakery pin (`59% OFF`, St. 310, BKK1).
   - Pulsing blue user location marker in BKK1.
   - Zoom in/out (+ / -), pan around Phnom Penh.
   - Tap the CAD Bakery pin -> Smoothly centers map and slides up the interactive store drawer with photo, price, and "Rescue Deal" button.
   - Tap "Rescue Deal" -> Opens checkout flow directly.
