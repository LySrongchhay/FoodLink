Section 1 · Design Language
Why AI Needs a Design Language
AI is a fast builder with no memory of your brand — the rulebook is the memory
1:00 – 1:35 PM
❌ Without a Design Language
  • Every generation invents new colors, fonts, and buttons — no two screens match.
  • The app looks like it was built by five different designers.
  • You burn time re-prompting the same fixes on every single screen.
✅ With a Design Language
  • One rulebook: palette, type scale, spacing, components, tone.
  • Paste it into any prompt — every screen comes out consistent.
  • Change the rulebook once, and the whole app follows.
A design language is a rulebook, not a picture: anyone (or any AI) who follows it builds screens that look like family.

Section 1 · Hands-On With Gemini
Prompt Lab: Build Your Design Language With Gemini
Gemini is your planning partner — strong at reasoning about brand, mood, and structure
gemini.google.com
Why Gemini for Planning?
  • Reasons, not just renders: it discusses mood, audience, and trade-offs before deciding.
  • Structured output: asks it for a spec and you get a clean, paste-ready rulebook.
  • Conversational refinement: "make it friendlier", "more contrast" — it rewrites the spec with you.
  • Tell it where the spec goes: the prompt says the answer will be pasted into AI Studio — so Gemini writes explicit, paste-ready values.
Fill-In Prompt (Copy & Use)
Act as a senior brand & product designer.
Create a design language for a [mobile + web] app
called [Name] that helps [target user]
to [main goal]. Mood: [e.g., friendly, fast].

This spec will be pasted into Google AI Studio to
build ONE HTML/CSS/JS app (web + mobile screens).
Write every value explicitly — exact hex codes,
px sizes, real font names — no chat references.

The spec must include:
1. Color palette — 5 hex codes (primary, secondary,
   background, surface, accent) with usage notes
2. Typography — font pairing + 3 sizes
   (heading, body, caption)
3. Spacing & shape — base unit, corner radius, shadow
4. Components — primary/secondary button, card,
   input field, nav bar
5. Tone of voice — 3 adjectives + example labels

Build & Style
What "Full Look & Feel" Means
  • Real palette, type scale, and spacing replace all placeholders.
  • Buttons, cards, inputs, and nav restyled as the spec's components.
  • Tone of voice applied to every label and message.
  • Both targets: a desktop web layout and a mobile layout of every screen.
The Follow-Up Prompt
Now apply the design language fully.

- Desktop web layout AND a mobile layout
  for every screen
- Same palette, type scale, spacing and
  components everywhere
- Responsive: cards stack and nav collapses
  on small screens
- Keep the JS screen navigation working

Live Fixes
What We Check Together
  • Click through the whole flow — any dead ends?
  • Does every screen match the palette and type scale from the spec?
  • Is the primary button obvious on every screen?
  • Does the mobile layout really work at phone width?
Micro-Prompts That Fix It
"Use only the palette from the design language."
"Increase spacing between sections to the base unit."
"Make the primary button accent-colored and larger."
"Stack the cards vertically at phone width."

Promote It: Demo Video with Google Veo
A working app deserves a story — capture proof, then generate the cinematic intro
50 Mins
A. Record Your Walkthrough (~20 Mins)
  • Open your canteen.html in the browser.
  • Screen record one complete user journey — Browse to Confirmation (Windows: Win + Alt + R, Mac: Cmd + Shift + 5).
  • Keep it under 90 seconds — show, don't tell.
  • Record both desktop and mobile views if you can.
B. Veo Promo Clip (~25 Mins)
  • Google Veo = Google's generative video model (free with a Google account).
  • Generate a cinematic 5–10 second intro clip that sets the scene for your app.
  • Sample prompt: "Cinematic over-the-shoulder shot of a college student in a bustling campus cafe, smiling while ordering lunch on a modern smartphone app, warm sunlight, 4k."
Final 5 mins: play your clip for a neighboring team — walkthrough video + Veo intro = instant pitch.

The Take-Home Cheatsheet: The 5-Step Loop
Keep this workflow on your desk for every future idea
The Master Framework
1. PLAN

Write your design language with Gemini. Colors, type, spacing, components, tone.

2. SKELETON

Paste the spec into AI Studio. One HTML/CSS/JS file, all screens, working nav.

3. POLISH

Apply the full look & feel — web + mobile. Fix live with micro-prompts.

4. PRACTICE

Download the file. Test locally, web + mobile. Note every bug you find.

5. PROMOTE

Record a 90-second walkthrough, add a Veo intro clip. Share the pitch.
